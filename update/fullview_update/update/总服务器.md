你的环境是 **Windows + PowerShell（远程 SSH）**。要在 SSH 断开后仍保持 8000 端口监听，关键是：**不要用当前终端里直接 `python dev-server.py`（SSH 一断进程通常会一起被杀）**，而是用**独立后台进程**启动。

---

## 一次性准备（防火墙，只需做一次）

在 **管理员 PowerShell** 里执行：

```powershell
netsh advfirewall firewall add rule name="Fullview Port 8000" dir=in action=allow protocol=TCP localport=8000
```

---

## 推荐：后台启动（SSH 断了也继续跑）

在普通 PowerShell 里执行：

```powershell
Set-Location "C:\Users\DELL\Desktop\icu\BME_1325_Full_Vis\full_view"

Start-Process python `
  -ArgumentList "dev-server.py","8000" `
  -WorkingDirectory "C:\Users\DELL\Desktop\icu\BME_1325_Full_Vis\full_view" `
  -WindowStyle Hidden `
  -RedirectStandardOutput "C:\Users\DELL\Desktop\icu\BME_1325_Full_Vis\full_view\server.log" `
  -RedirectStandardError "C:\Users\DELL\Desktop\icu\BME_1325_Full_Vis\full_view\server.err.log"
```

这条命令会：
- 在 `8000` 端口启动服务
- 进程与当前 SSH 会话分离
- 日志写到 `server.log` / `server.err.log`

## 检查是否在运行

```powershell
Get-NetTCPConnection -LocalPort 8000 -State Listen
```

或：

```powershell
Invoke-RestMethod "http://127.0.0.1:8000/api/health"
```

看日志：

```powershell
Get-Content "C:\Users\DELL\Desktop\icu\BME_1325_Full_Vis\full_view\server.log" -Tail 20
```

## 停止服务

```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force }
```

---

## 如果 8000 已被占用，先清掉再启动

```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force }
```

然后再执行上面的 `Start-Process` 启动命令。

---

## 不推荐的方式（SSH 断了会停）

下面这种方式**不要**用，如果你要“断 SSH 仍开着”：

```powershell
# 不要这样
python dev-server.py 8000
```
